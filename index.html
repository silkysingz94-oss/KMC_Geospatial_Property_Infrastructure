Methodology
1. Load Census EA GeoJSON from GitHub.
2. Identify Kanifing EAs using the LGA attribute.
3. Filter selected EAs by district and ward.
4. Query OSM features within the selected EA bounding box.
5. Apply exact geometry intersection against selected EA polygons.
6. Calculate infrastructure counts and census EA population/household totals.
Road indicators represent mapped road features. They are not road length or road density calculations.
